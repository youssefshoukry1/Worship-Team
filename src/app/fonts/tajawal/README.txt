Tajawal - local Arabic UI font

Source: https://github.com/google/fonts/tree/main/ofl/tajawal
License: SIL Open Font License 1.1 (see OFL.txt).

Regular (400), Medium (500), and Bold (700) were downloaded from Google's
font repository and converted from TTF to WOFF2 with fontTools and Brotli.
All original glyphs are retained, including Arabic, diacritics, and Latin.
The three WOFF2 files total 62,308 bytes and are bundled by next/font/local.
No font provider or font API is contacted at runtime.
